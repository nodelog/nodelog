# NODELOG 设计语言 · 「登记簿 / The Numbered Register」

> 版本 1.0 · 面向既有 Express + EJS SSR 博客的**换视觉世界**方案（Read 模式 / 内容站）
> 交付物：本文件。前端按本文件另建 `design-language/tokens.css` 与 `design-language/index.html`（三页 × 明暗 × 三断点呈现页）。
> **不改动** `DESIGN.md` / `design-tokens.json` / `design-choice.json` / `public/css/theme.css` / 任何 `views/*.ejs`。
> 所有数值可直接写进 CSS；零新增依赖（无 Web 字体 CDN、无图标库、无构建步骤）。图标一律内联 SVG（16 / 20 / 24px，stroke 1.75，统一 round cap/join）。

## 0. 一句话主张

> **把 NODELOG 当成一本按序累积、永不清空的工程登记簿：每篇文章是带归档坐标（序号 + 日期 + 观测时长）的一条登记，整站靠一条贯穿首页 / 列表 / 文章的「左缘登记轨」和统一阅读栏组织，而不是把文章摊成等尺寸卡片。**

只有名字里带 **LOG**、且品牌自称「从第一篇到第十万篇」的站点，才会把「累积序号」当作**阅读动线的骨架**。把站名换成任何以 feed / 推荐流 / 卡片网格为核心的技术博客（掘金、Ghost、Vercel Blog），登记轨立刻退化成无意义的装饰，整页就塌了 —— 这就是竞品测试（把真实竞品代进这句话不成立）。遮住站名仍认得出：一条 72px 编号轨 + 一枚 24×2px 刻度 + 连续基线，指向的是记录本，不是博客模板。

### 0.1 产品身份锚点（实读证据，方向的真值来源）

`views/common/meta-front.ejs` 实读：`:5` 作者「匠子心」；`:7` / `:8` keywords 与 description 均为「…技术博客,**打造最快的搜索体验**,nodejs,express,monogodb,code,**博客,日志,技术**」；`:16` `<title>…-打造最快的搜索体验`。**产品自己说自己是「找得到」，不是「发布 / 极客 / 终端」。**

这恰好补上主张里最关键的一环：**登记簿不是审美选择，是一套索引装置** —— 编号是坐标、轨是索引栏、连续基线是检索顺序。用户能按 `№ 0137` 定位一篇，也能在顶栏常驻检索框里直接找到它。因此本方案**继承**上一轮 `DESIGN.md §0` 的语义组合「**顶栏常驻检索 + 首屏即正文**」（`.search-input` 留在书脊带、首屏就是最新一条真实登记而非 Hero 口号），但**不继承**它的黑白极简视觉表达：底色改冷石墨纸、强调色改解出来的青绿、层级改登记轨与三级材质台阶、字体改三族角色分工。

一句话验收：**遮住站名，这仍是一本「可检索」的工程登记簿**。换成只做内容流、没有「按坐标找一篇」这件事的站点，编号轨既无坐标意义也无检索用途，主张立刻不成立。

## 2. 整体视觉气质

**具象描述**：一间夜里还亮着台灯的工程档案室。冷灰的登记纸（不是暖米黄），深墨色字迹，三级明度的纸面代替一切描边盒；一条细竖线把「编号」和「正文」分开，每条登记起始处有一枚极小的青绿刻度，像钢印章盖下的定位痕。字有两种材质：中文标题与正文是无衬线系统字，文章大标题与站名是系统衬线（只在 ≥20px 时出现）；等宽字只出现在代码、日期、序号里，绝不爬上导航和按钮。页面安静、密而有节奏，图只有一张是决定性的，其余都是文字。深色不是反色：是一间关了大灯、只留凹槽灯的同一间房，`bg → surface-2` 变成更深的凹槽，`surface` 变成略亮的台面。

**三条禁用（点名避开）**：

1. **禁「开发者博客默认皮」**：黑白极简 + 一枚饱和蓝 + 等宽字体套满 UI 铬层 + `U+276F 提示符` / `# ` / 闪烁光标 / 点阵背景 / 渐变下划线的终端贴皮 —— 正是现状 `theme.css:148–207`。
2. **禁「第三波修好药方」**：米黄 / 奶油底 + 陶土锈橙 + 高对比衬线大斜体 + 满屏发丝线的报纸腔。`design-tells.md §三之二` 指出这是「照着批评意见改」改出来的下一波平均脸，识别度反而更高。本方案底色冷灰（H≈192°，非 40–100° 暖区），无衬线主体，衬线只用于 4 处大字号。
3. **禁「居中 Hero + 三张等尺寸卡 + 三档定价」及其同族**：圆角一把梭、渐变 / 渐变文字 / 发光、静止阴影、图标功能卡、pill 徽章、每节 eyebrow 小标签（`design-tells.md §二` 12 条 + 编排 P0）。

**签名特征自查**：本方案命中 12 条 AI 签名 **0 条**（登记轨、归档坐标、单刻度均为自造装置，不在清单内），满足 `design-tells.md §三` 「单页 ≤2 条」。

**删掉贴皮之后，补上的不是装饰，是 4 样结构性东西**（`design-voice.md`「删掉之后必须补上」+ `design-tells.md §三之三`「删干净 ≠ 好看」）：

1. **更大的尺度** —— T8 54px / 正文 17px = **3.18×**，首屏只有这一位主角，其余全部降级；
2. **完整内容** —— 首屏是「最新一条登记」的真实标题 / 摘要 / meta / 归档坐标，不是口号，也不是三张功能卡；
3. **为主题做的图** —— 站内无真实摄影素材（见 §6），改用**内容型内联 SVG「登记卡图示」**，画的是本站索引结构本身，不是库存插画、不是灰块；
4. **一整块平涂颜色** —— 页脚满幅 `--surface-2` 带（深色 `#0C151A`），无辉光、无渐变、无点阵。

**三条评审尺子自检**：一屏一个主角且尺度比 3.18×（≥3），层级只靠**大小 / 疏密 / 明暗**（字重 500 仅作同档次级区分、不作层级机制；当前态与链接不变色、不加小标签）；所有标题 `text-wrap: balance` 后**人工看一眼断点**，首屏文字跨满主栏、图示只占 12%，右侧是**承载真实元信息的边注区**（§9.4，不是空栏）；浅色三级底色 **21.0%** 绝对亮度差、深色 **3.08×** 相对差，均超过 8% 判定线。

**避第三波的具体动作**（不是只喊口号）：底色 `#EDF1F2` 色相 ≈192°（不在 40–100° 暖区）、饱和度 0.16，不是奶油 / 米黄；主体字体是无衬线系统栈，衬线只出现在 4 处 ≥20px 的大字号，**没有斜体衬线大标题**；分隔只用条目间一条 1px 基线 + 登记轨一条竖线，**不是满屏发丝线 / 密栏报纸腔**；强调色是解出来的青绿 `#1B7174`，不是陶土 / 锈橙。三条同时成立，才叫避开了第三波。

### 3.2 语义四件套（背景 8–12% tint + 深一档文字 + 内联 SVG + 人话文案，四件缺一不可）

| 语义 | 浅 tint / ink | 深 tint / ink | 实测 ink on tint |
|---|---|---|---|
| `info`（蓝 ≈211°） | `#E4EDF6` / `#27598F` | `#152A3C` / `#9DC2EC` | 6.09:1 / 7.95:1 |
| `warning`（琥珀 ≈40°） | `#F7EEDC` / `#8A5A10` | `#302514` / `#E7BA69` | 5.13:1 / 8.30:1 |
| `danger`（红 ≈5°） | `#F9E6E4` / `#A32D27` | `#331B1A` / `#F29B95` | 5.90:1 / 7.54:1 |
| `success`（绿，复用主色族 ≈182°） | `#E7F1F1` / `#1B7174` | `#15302F` / `#7CD5CA` | 4.99:1 / 8.18:1 |

`success` 复用主色族以免引入第 5 个色相；`info`(211°) 与 `accent`(182°) 相差 29°，靠 **SVG 图标 + 文案 + tint 形状** 作第二信号（`accessibility.md §一·4`），不靠色相区分。

### 3.3 主色是算出来的，不是审美偏好

求解过程（脚本实跑，非挑色卡）：

1. **定色相**：必须避开四个语义色相（211 / 40 / 5 / 182 中的前三个）且不是紫→粉区间 → 取 **H = 182°（青绿）**，S 固定 0.62。
2. **定明度**：解两个硬约束的交集 —— `C1`：白字写在主色上 ≥ 4.5:1（按钮可读）；`C2`：主色作为控件边界画在 `bg` 上 ≥ 3.0:1（WCAG 1.4.11）。扫描 L：L=0.32 时 `白字 4.63 / 边界 4.07` 勉强合格，**取留余量的 L=0.28 → `#1B7174`**（`白字 5.74 / 边界 5.04`）。
3. **深色单独再解一次**（不是把 `#1B7174` 提亮）：深色按钮上是**深字** `#0C151A`，约束方向反转 → 主色必须够亮。同色相族取 H=173°（向绿偏 9°，补偿暗背景下的 Bezold–Brücke 色度感知偏移）、S=0.51、L=0.66 → **`#7CD5CA`**（`深字 10.75 / 边界 9.99`）。
4. hover / press 是同一条 H/S 曲线上 L 的单调外推（浅 0.22 / 0.18，深 0.74 / 0.80），全部复测过对比度。

> 结论：**两个主色是同一「青绿族」在两套背景下各自解对比度方程的结果**，不是「一个蓝 + 反色」。

### 3.5 强调色面积上限

`--accent` 全页可见只允许出现在 **4 类位置**：① 每条登记起始的 **24×2px 刻度**（可重复 N 次，算 1 类）② 当前导航项左侧 **2px 竖线** ③ **全页唯一 1 个实填充主按钮** ④ `:focus-visible` 环（瞬时，不计静态面积）。
最坏页（首页：1 主按钮 96×44 + 8 条刻度 24×2 + 1 竖线 2×20）≈ **1.3% 面积**，远低于 5% 硬上限。
因此 `.brand-cta`、`.pager-link[current]`、`.chip[current]`、正文链接**一律不用强调色填充**（改用 `--ink` 500 字重 + `--surface-2` 底 / 下划线）。`design-voice.md §五`：强调色出现五处以上就不再意味着「这里」。

- **每页最多启用 5 档**；承担层级跳变的档位按刻度**隔位取用**（T1→T3→T5→T7 或 T2→T4→T6→T8），隔位比值依次 1.42 / 1.53 / 1.54 / 1.57 / 1.45 / 1.69，**全部 ≥1.25×**（`measured-craft.md §二`）。T1/T2 同属辅助层，不参与层级跳变。
- 每页启用档：首页 `T1 T2 T3 T5 T8`；列表 `T1 T2 T3 T6 T7`；文章 `T1 T2 T3 T5 T7`（T4 仅在有引言时替换 T5，不叠加）。
- 功能字重上限 **500**（`ui-judgment` 五条红线之一）；禁用 600 / 700；层级靠字号 + 色深，不靠加粗。

### 4.3 中英混排 / 行宽 / 移动端缩放

- 中文行高按表，**不继承拉丁紧行高**；中文标点全角，`line-break: strict`，`word-break: normal`；中英混排时行高取中文值 1.75。
- 拉丁文 / 数字在 `--font-serif`、`--font-mono` 里可用 `.01–.02em` 正字距；**本语言禁用全大写标签**，故不存在「全大写配 0.06–0.1em」的场景。
- **阅读行宽 `--measure: 680px`（40 汉字 @17px）**，写作 `max-width: min(680px, 100%)`。**禁用 `ch` 单位**：中文环境下 `1ch` 可能等于 `1em`，`68ch` 会撑到 1100px+，正是现状文章页行宽失控的来源（`measured-craft.md §二` 中文 ≤40 字）。
- **移动端缩放**：`T3 = 17px` 三断点 / 明暗 / 200% 缩放**一律不缩**（避免 iOS 输入框强制缩放、正文变糊）。只缩标题：`T8 54→44(768–1023)→36(<768)`、`T7 40→34→30`、`T6 32→28→26`、`T5 26→24→22`、`T4 22→21→20`、`T2/T1` 不缩（14/12 ≥ 功能文字 11px 下限）。375 / 390 屏标题 ≤2 行（中文 ≤16 字/行），手动断行 + `text-wrap: balance` 且必须看一眼断点。

| 场景 | 值 |
|---|---|
| 节内元素（标题→摘要→meta→chip） | `12 / 16 / 24` |

**相邻两节版式家族不重复**（`design-voice.md §三`，给每节写一个词，同一个词连着出现两次即错）：

- 首页：`满幅(书脊带) → 分栏+图示(头条) → 连续列表(登记流) → 索引表格(侧栏) → 满幅(页脚)`
- 列表页：`陈述(页头) → 连续索引列表(条目) → 表格(分页) → 索引表格(侧栏)`

**z-index 七层固定刻度**（`visual-defect-taxonomy.md §一·7`）：`--z-base:0 / dropdown:100 / sticky:200 / overlay:300 / modal:400 / toast:500 / tooltip:600`，禁止裸 `9999`。

## 6. 图文比例（**无真实图片是默认路径，不是降级路径**）

### 6.1 资产实况（决定了本节的写法）

`public/images/` 实读：只有 `favicon.ico / logo.png / share-cover.png / search-icon.png / top.gif / top.png / ft_bg.png / qq-disable.png / qq-enable.jpg / weibo.png / weixin.png / weixinlogo.png` 等**功能性小图**（站点图标、分享缩略图、二维码登录图标、旧页脚底图），**没有任何可用的真实摄影图、插画或内容配图**。

所以本语言**不建立在「拿一张高质量照片撑首屏」上**，也不允许灰块 / 占位框 / 渐变假图。首屏的视觉重量由 **排版尺度 + 内容型内联 SVG 图示 + 一整块平涂色带** 三者承担 —— 纯排版本身即为视觉。这同时避开 `design-voice.md §六`「用色块假装图片」与 `design-tells.md §二·11`「库存感插画」。

### 6.2 可执行规则（按比例写死，不靠「配张图」）

| 页面 / 场景 | 图 | 文字 / 排版 | 具体值 |
|---|---|---|---|
| **首页首屏** `.post-card--lead`（**默认无封面**） | **1 张内容型内联 SVG「登记卡图示」** | 真实标题 T8 54px + T4 摘要 + T2 meta + 归档坐标 | 图示置于「登记带」内：`--surface-2` 满栏底 `728 × 200px`，图示 `320 × 160px` 右对齐，占首屏面积 ≈ **12%**；文字 + 排版 ≈ **88%**。**0 张摄影图** |
| **首页首屏**（真有 `doc.cover`） | 1 张用户上传封面 | 同上 | 封面 `728 × 485px`（3:2），图示撤下；图 ≈ **38%** / 文字 ≈ **62%**；`object-fit: cover`，`decoding="async"`，首屏不 `lazy` |
| **首页登记条目** `.post-card--grid` | **默认 0 图** | 标题 T5 + 摘要 T4 2 行 + meta T2 + 刻度 | 有 cover 时才显示 `96 × 64px`(3:2) 右对齐缩略图，占条目 ≤ **12%**，每页 ≤6 枚；无 cover 时该位置由 `24×2px` 刻度 + 归档坐标占据，**不留空** |
| **列表页** `.post-card--list` | **0%** | 纯索引：轨内坐标 + T6 标题 + T4 摘要 + T2 meta | 无图、无缩略图、无占位 |
| **文章页** `.article-content` | 用户上传图或**结构型内联 SVG** | 正文 680px / 17px / 1.75 | 图 ≤ `680px` 栏宽、单张占栏 100%；代码块 / 图表 ≤ 栏宽且高度 ≤ `栏宽 × 0.66`；**图表 + 代码块合计 ≤ 正文滚动长度 30%**；无图时用目录树 / 时序 / 对比型 SVG，**不留空位** |
| **统一裁切** | 仅当存在真实 cover 时生效 | — | 一律 **3:2**，`object-fit: cover`；禁止现状混用 `2:1`(lead 1280×640) 与 `16:9`(grid 640×360) |
| **figcaption** | 每张图 / 每个信息型 SVG | T1 12px 一句「它在证明什么」 | 装饰性图 `alt=""`；信息型 SVG 配 `role="img"` + `<title>` / `aria-label` |

### 6.3 「登记卡图示」内联 SVG 规格（内容型，不是装饰插画）

画的是**本站自己的索引结构**，因此换成别站不成立：

- 画布 `320 × 160`，`viewBox="0 0 320 160"`，`role="img"` + `aria-label="登记簿索引结构示意：编号轨、连续基线与当前条目定位"`。
- 元素：`x=0` 一条 `1px` 竖线（`--border-strong`）；`y=32 / 72 / 112` 三条 `1px` 横线（`--border`）；每行右侧一个 `tabular-nums` 编号 `№ 0135 / 0136 / 0137`（`--font-mono 12px` `--muted`，右对齐到 `x=312`）；**第一行** `x=0..24, y=30` 一枚 `24 × 2px` `--accent` 刻度 —— 与页面里真实刻度同尺寸同色。
- 全部 `stroke-width` 只用 `1` 或 `2`；`fill` 只用 `--surface-2` / `--accent`；**无渐变、无发光、无阴影、无圆角 >2px、无 emoji、无动画**。
- 明暗两套**只换 token、不改结构**：深色下 `--surface-2` 自动变 `#0C151A`、`--accent` 自动变 `#7CD5CA`。
- 旁配 T1 12px figcaption：「按编号定位一条登记 —— 本站的检索方式」。

### 6.4 无封面 / 无图降级（**默认路径**）

「登记带」= `--surface-2` 满栏平涂 `728 × 200px`（移动端 `100% × 160px`）+ 左侧大号归档坐标（T7 40px `--font-mono`，如 `№ 0137`）+ 日期 `2026-03-14` + `24×2px` 主色刻度 + 右侧 §6.3 的内容型 SVG；标题直接落在带**下方**，不压在图上。

**禁止**：灰块、「图片位置」占位、CSS 渐变假图、`background-image` 伪图、`top.gif` 之类动图（会引入循环动效，违反 §8 动效预算）、`ft_bg.png` 旧底图、任何「待补图」标注。
`search-icon.png` 由内联 SVG 搜索图标（20px，stroke 1.75）替代；`logo.png` / `share-cover.png` 仅作元数据用，**不进入页面视觉**。

### 6.5 三条评审尺子对本节的约束

- **首屏文字不挤在左 40%**：登记带横贯主栏 728px，图示右对齐但只占 12%，文字块跨满主栏宽度，不产生「左侧一窄栏 + 右侧死地」。
- **明暗两级底色可见**：登记带用 `--surface-2` 与 `--bg` 形成台阶（浅 21.0% / 深 3.08×），不是靠 1px 描边假装分层。
- **有意偏离登记**：`measured-craft.md §二`「首页 ≥4 张真实图片」适用于 **Persuade 落地页**；本站为 Read 模式内容站、且资产里根本无图，按内容优先走「**0 摄影图 + 1 张内容型 SVG + 纯排版**」。按该文 `§三` 的纪律明说：这是**取舍 + 资产约束，不是规律**，并在此登记。

| 等宽套满铬层 → 「统一」 | **两条锚线 A/B + 1120 唯一容器 + 9 档间距刻度**，统一来自栅格而非字体 |

## 8. 交互状态与动效尺度

### 8.1 六态规格

| 态 | 规格 |
|---|---|
| **focus-visible** | `outline: 2px solid var(--ring); outline-offset: 2px; border-radius: inherit`；**禁止 `outline:none`**（除非同时给等价可见样式）；环不被 `overflow:hidden` 裁掉；`.skip-link` 是第一个可聚焦元素；弹窗焦点陷阱 + 关闭归还触发元素（`accessibility.md §三`） |
| **hover** | 只改颜色 / 下划线，`150ms ease-out`；**无位移、无抬升、无阴影、无放大**；链接 1px → 2px `--ink` 下划线；按钮 `--accent → --accent-hover` |
| **active** | `0ms` 瞬时切到 `--accent-press`，**无 scale / 无 translate** |
| **current** | `.current-menu` / `.breadcrumb .active` / `.pager-link[current]` / `.chip[current]`：统一 **`--ink` + 500 字重 + 2px 竖线或下划线 + `aria-current="page"`**；**不用色块填充、不用 accent**（省面积 + 不制造第二套语言） |
| **loading** | 列表 / 页用**静态骨架** `.state-skeleton`（`--surface-2` 矩形，**无微光扫过**）；按钮用 `disabled` + 16px 内联 SVG spinner（**唯一允许的循环动效**，`700ms linear`）+ 人话文案「正在保存…」；`prefers-reduced-motion` 下 spinner 换成静态文字 |
| **disabled** | **不用 `opacity`**（会把文字压到 4.5:1 以下）；改 `--surface-2` 底 + `--muted` 字（6.11:1）+ `1px solid --border` + `aria-disabled="true"` + `cursor:not-allowed`，仍保留 ≥44×44 触控区 |

**九态矩阵**覆盖 `Default / Hover / Focus / Active / Disabled / Loading / Error / Empty / Success`；`.state` 四类（loading / empty / error / success）已由 `common/state.ejs` 提供 DOM 契约，本语言只改样式与文案形状。

### 8.2 允许的 3 处动效（多一处即删）

| # | 场景 | 时长 / 缓动 / 位移 |
|---|---|---|
| 1 | 链接 / 按钮颜色与下划线变化 | `150ms ease-out`，**0 位移** |
| 2 | 下拉 / 搜索建议浮层展开 | `200ms cubic-bezier(.2,.7,.2,1)`，`opacity 0→1` + `translateY(-4px→0)`（**全站唯一位移**） |
| 3 | 就地状态块 / Toast 淡入 | `160ms ease-out`，**仅 opacity**，一次，不重复 |

主题切换**瞬时换色，不做整页淡入淡出**（避免 FOUC 与白屏闪烁）。

**`prefers-reduced-motion: reduce`**：上述 3 处 `transition-duration` 全部降为 `0.01ms`，spinner `animation: none`，所有 `animation` 一律 `none`；视觉状态（颜色 / 下划线 / 字重）**保留**，只是去掉过程。

**明确禁止**：闪烁光标、点阵背景、渐变下划线生长、封面缩放、逐节滚动揭示、骨架微光扫过、脉冲 / 浮动 / 呼吸、任何 >200ms 的装饰动画、任何持续循环动画（spinner 除外）、`scroll-behavior: smooth` 的自动滚动劫持。

## 9. 三页面应用编排

### 9.1 跨页签名元素（遮住站名还能认出来）

> **「登记轨 + 单刻度基线」**：内容左沿一条 `--rail 72px`（移动 48px）的登记轨，轨内**右对齐** `tabular-nums` 归档坐标 —— 真实文档序号 `№ 0137` 与真实 `createTime` 日期 `2026-03-14`，T1 12px `--font-mono` / `--muted`；轨右侧 `1px solid --border` 竖线贯穿全页；**每条登记起始处一枚 `24 × 2px` `--accent` 刻度**。三页同位置、同尺寸、同色。

**为什么这不是被禁的 `01/02/03` 章节编号**：`design-tells.md §三之四` 把序号列为「默认（可挣回）」而非硬禁。此处挣回的理由是产品自身的材料 —— 名字里的 **LOG**、品牌自述「**从第一篇到第十万篇**」，以及 `meta-front.ejs` 的「**打造最快的搜索体验**」，序号是**绑定真实文档、可被检索的归档坐标**，不是节标题前缀。护栏写死：① 序号只出现在登记轨与文章页头，**绝不出现在章节标题上方**；② 必须是右对齐 tabular 数字，不做 `01 / 02 / 03` 补零连排；③ 数据与 `createTime` / 文档 id 绑定，无数据时**留空不编造**；④ 语义上用 `<ol>` / `<time datetime>`。

**签名元素承担的是产品语义，不是装饰**：`meta-front.ejs` 说明本站的核心是「检索 / 索引 / 找到」。登记轨 = 索引栏，编号 = 坐标，连续基线 = 检索顺序，顶栏 `.search-input` = 直达入口，§6.3 的 SVG 画的就是这套索引结构。因此「顶栏常驻检索 + 首屏即正文 + 左缘登记轨」三件事是**同一套检索装置**的三个部件，不是三个装饰。上一轮 `DESIGN.md §0` 的前两件语义在此继承，视觉表达（黑白极简 / 墨蓝 / 终端贴皮）全部换掉。

## 10. 移动端适配

| 断点 | 导航 | 网格 | 侧栏 | 阅读行宽 |
|---|---|---|---|---|
| **≥1024** | 单行书脊带 `64px`，主导航 + 工具全展开，搜索 `220px` | 主栏 `728` + 侧栏 `280`；文章 `72 / 680 / 232` | 右列固定 280px | `680px`（40 汉字） |

| **<768** | `56px` 汉堡 `.navbar-toggle` 展开为全宽下拉；搜索占满一行 `100%`；`.theme-toggle` 保持 `44×44` | **单列**；轨收窄为 **`48px` + 16px 沟**（轨内只留年份 `2026`，序号移到标题上方一行 T1 12px） | 下方单列，节间 `48px` | 正文 = `视口 − 2×20 − 48 − 16`；**T3 17px 不缩** |

**375 / 390 重点**：

- `375` → 内容宽 `335px`，正文 `271px`（≈16 汉字/行）；`390` → 内容宽 `350px`，正文 `286px`。
- 标题 T7 → 30px，**≤2 行**（中文 ≤16 字/行），手动断在语义处 + `text-wrap: balance` 并看一眼断点；`T8` → 36px 同理。
- **零横向滚动**：`pre` / `table` / 长代码块一律 `overflow-x: auto` **内部滚动**；页面级 `overflow-x: hidden` 兜底；所有栏宽用 `minmax(0,1fr)` / `min()`，不写死固定 px；`img { max-width:100%; height:auto }`。

- **触控**：全部可点 ≥ `44×44px`，相邻 ≥ `8px`；`.chip` 视觉是下划线文字但 `min-height:44px`；`.pager-link` `44×44`；`.theme-toggle` `44×44`。

## 12. 备选方向（各一句 + 核心差异 + 代价，供拍板换方向用）

- **B「索引卡柜 / Card Catalog」**：以图书馆卡片目录为原型，每篇文章是一张带脊线的横向索引卡，三页靠「抽屉编号 + 卡片脊」串联。**差异**：推荐方向是**连续编年流**（纵向、无盒），本方向是**离散卡片**（横向、有盒）。**代价**：重新引入「盒子」，需靠大量留白与统一脊线压住模板感；移动端极易退化成「同款卡片行」（`measured-craft.md §三` 弱站 26% / 强站 7%）。
- **C「双栏批注 / Marginalia」**：以工程手册的「正文 + 外缘批注」为原型，把边注栏扩到 320px 并让首页 / 列表页也有批注（术语、版本、相关链接）。**差异**：推荐方向只在**文章页**给一处大留白，本方向把批注变成全站装置。**代价**：首页 / 列表信息密度上升，内容优先被削弱；若无真实批注数据会变成空栏（`measured-craft.md §四之二` 第 11 遍「一栏小字两边死地」）。
