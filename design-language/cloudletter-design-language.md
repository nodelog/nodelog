# 云笺 · Cloudletter — 博客 UI 设计语言

> 设计溯源：以 `https://saas.jiangzi.xin/`（链付收银 SAAS）的视觉与交互调性为母本，重构为面向**长文阅读与内容展示**的博客设计语言。
> 原站调性关键词：轻盈、温暖、可信、现代、留白充足、圆润、柔光阴影、蓝+绿「科技+温度」配色。
> 迁移原则：**保留调性，强化阅读**——收束装饰密度（pastel 四宫格、梯度过载），放大阅读舒适度（阅读栏宽、行高、稳定字阶）。

## 1. 设计原则

1. **轻盈留白（Airy）**——大留白、浅底、柔光，让内容呼吸；模块纵向间距 ≥64px，不堆砌。
2. **温暖可信（Warm & Trusted）**——蓝主色给「可信」，绿次色给「温度」，pastel 仅作极小面积点缀（标签/图标底）。
3. **内容优先（Content-first）**——一切装饰退居衬底；正文阅读栏固定 ~720px、稳定 17px、行高 1.8，装饰不抢字。
4. **克制层次（Restrained Hierarchy）**——靠字重（700 标题 vs 400 正文）、留白、单一主色建立层级，不靠多色与重影。
5. **一致圆润（Consistent Roundness）**——全站统一圆角刻度，胶囊按钮 + 16px 卡 + 12px 控件，亲和无锐角。
6. **柔光而非硬影（Soft glow, not hard drop）**——阴影一律低透明、大扩散；仅浮层（下拉/弹层）用深一档，表面卡用极浅一档。

## 2. 色彩规范

### 2.1 浅色（默认）

| 语义 | Token | Hex | 用途 |
|---|---|---|---|
| 页面底 | `--bg` | `#EEF2FA` | 全站浅薰衣草蓝底 |
| 表面 | `--surface` | `#FFFFFF` | 卡片 / 导航 / 浮层 |
| 次表面 | `--surface-2` | `#F4F6FB` | 区块底 / 代码块 / 引用底 / 输入框底 |
| 描边 | `--border` | `#E3E8F0` | 装饰分隔（不承载信息） |
| 强描边 | `--border-strong` | `#CBD5E1` | 控件边界（≥3:1） |
| 墨色 | `--ink` | `#1F2937` | 标题 / 正文 |
| 弱墨 | `--muted` | `#64748B` | 元信息 / 辅助 |
| 主色 | `--accent` | `#2563EB` | 导航 current、链接、主按钮、标题高亮 |
| 主色-hover | `--accent-hover` | `#1D4ED8` | |
| 主色-press | `--accent-press` | `#1E40AF` | |
| 次色（温暖） | `--accent-2` | `#10B981` | 订阅 / 写文章 / 成功状态 |
| 次色-hover | `--accent-2-hover` | `#059669` | |
| 品牌渐变起 | `--brand-from` | `#4A54E8` | 仅 logo 标 / 可选 hero 微渐变 |
| 品牌渐变止 | `--brand-to` | `#5B6CFF` | |
| 字色（on accent） | `--on-accent` | `#FFFFFF` | 主/次按钮白字 |

**Pastel 点缀（极小面积，仅标签/图标底，不进主色族）**：
`--pastel-blue:#E8F0FE` · `--pastel-green:#E6F6EF` · `--pastel-peach:#FDEFE6` · `--pastel-pink:#FCE8F1`

**语义四件套**（状态必配图标+深一档字+人话文案，不只靠底色）：
`--info #2563EB/#E8F0FE` · `--success #10B981/#E6F6EF` · `--warning #D97706/#FEF3E2` · `--danger #DC2626/#FDECEC`

### 2.2 深色（保持温暖，不转冷黑）

| 语义 | Token | Hex |
|---|---|---|
| 页面底 | `--bg` | `#0F172A` |
| 表面 | `--surface` | `#192334` |
| 次表面 | `--surface-2` | `#121B29` |
| 描边 | `--border` | `#2A3647` |
| 强描边 | `--border-strong` | `#3C4A5E` |
| 墨色 | `--ink` | `#E8EDF4` |
| 弱墨 | `--muted` | `#94A3B8` |
| 主色 | `--accent` | `#5B8DEF`（提亮以保对比） |
| 次色 | `--accent-2` | `#34D399` |

暗色下阴影几乎不可见，靠 `--border` 建立层次；柔光改为极淡 `rgba(0,0,0,.35)`。

### 2.3 强调色使用纪律
- 主色面积 ≤ 全页 ~8%；次色 ≤ ~3%（仅 1–2 个 CTA）。
- 标题高亮：每篇标题最多高亮 **1** 个关键词（`<mark class="hl">`），其余为 `--ink`。
- 不出现紫粉渐变文字、不发光描边、不毛玻璃。

## 3. 字体规范

### 3.1 字族（与原站一致：全无衬线）
```
--font-sans: -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei",
             "Hiragino Sans GB", "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
--font-mono: "SF Mono", "JetBrains Mono", "Fira Code", Consolas, "Courier New", monospace;
```
正文与全部 UI 铬层用 `--font-sans`；`pre/code`、序号、表格数字用 `--font-mono` + `tabular-nums`。

### 3.2 字阶（8 档，阅读基线稳定）

| Token | 尺寸 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| `--fs-display` | 40px | 1.25 | 700 | 文章 h1（移动 30px） |
| `--fs-h1` | 32px | 1.3 | 700 | 页面/栏目标题 |
| `--fs-h2` | 24px | 1.4 | 600 | 文章 h2 |
| `--fs-h3` | 20px | 1.5 | 600 | 文章 h3 / 卡片标题 |
| `--fs-lead` | 19px | 1.7 | 400 | 首段导读（article lead） |
| `--fs-body` | 17px | 1.8 | 400 | **正文基线**（三断点不缩） |
| `--fs-body-sm` | 15px | 1.7 | 400 | 元信息 / 侧栏 / 按钮 |
| `--fs-small` | 13px | 1.5 | 500 | 胶囊标签 / 脚注 |

### 3.3 标题高亮
标题中可嵌 `<mark class="hl">关键词</mark>` → `background: color-mix(in srgb, var(--accent) 14%, transparent); color: var(--accent); border-radius: 4px; padding: 0 4px;` 复刻原站蓝词高亮。

## 4. 间距 · 圆角 · 阴影 · 栅格

### 4.1 间距刻度（4px 基数，宽松优先）
`--sp-1:4 · --sp-2:8 · --sp-3:12 · --sp-4:16 · --sp-5:24 · --sp-6:32 · --sp-7:48 · --sp-8:64 · --sp-9:96`
模块纵向间距用 `--sp-8/--sp-9`；卡内边距 `--sp-5/--sp-6`；元素间隙 `--sp-3/--sp-4`。

### 4.2 圆角刻度（一致圆润）
`--radius-pill:999px`（按钮/胶囊标签）· `--radius-lg:16px`（卡片/封面）· `--radius:12px`（控件/代码块/引用）· `--radius-sm:8px`（小按钮/标签）· `--radius-xs:6px`（行内 code）。

### 4.3 阴影三档（柔光签名）
```
--shadow-sm: 0 1px 2px rgba(15,23,42,.04), 0 1px 3px rgba(15,23,42,.05);   /* 表面卡 */
--shadow:    0 4px 14px rgba(15,23,42,.06), 0 2px 4px rgba(15,23,42,.04);   /* 悬浮卡（hover 加深） */
--shadow-lg: 0 12px 32px rgba(15,23,42,.12);                                /* 下拉/弹层浮层 */
--glow-accent: 0 6px 16px rgba(37,99,235,.22);                              /* 主按钮彩色微光 */
```
阅读栏（正文容器）**只用描边，不投影**，避免噪音。

### 4.4 栅格
- 页面容器 `--wrap:1200px`，居中，左右 `--sp-5` 内边距（移动 `--sp-4`）。
- 文章页双栏（≥1024px）：主栏 `--measure:720px` + 右栏 `--aside:280px`，栏距 `--sp-7:48px`。
- 列表页卡片网格：≥1024 两列（`repeat(2,minmax(0,1fr))`，gap `--sp-6`）；<1024 单列。
- 断点：`--bp-md:768px` · `--bp-lg:1024px`。

## 5. 核心组件

### 5.1 导航 Header
- 白（暗色 `--surface`）吸顶，高 `--sp-8:64px`，底部 `1px --border` + 滚动时加 `--shadow-sm`。
- 左：蓝圆角方标（品牌渐变 `#4A54E8→#5B6CFF` + 单字/图标）+ 站名（700）+ 可选小蓝标「BLOG」。
- 中：分类横向菜单（500），hover → `--accent` + 2px 下划线滑入（150ms ease）；current → `--accent` 文字 + 常驻下划线。
- 右：**两胶囊按钮**——描边幽灵「登录」+ 实底次色（绿）「订阅 · 写文章」；搜索图标按钮；主题切换。
- 移动：汉堡 → 左滑抽屉（分类 + 按钮竖排）。
- 交互：下划线 `transition:150ms`；按钮 `transition:color/background 160ms, transform 120ms`。

### 5.2 文章列表 Article List（三形态）
1. **头条（featured）** 整宽大卡：封面（16px 圆角，hover 轻微 scale 1.03 裁剪）+ 胶囊分类标签（pastel 底）+ 标题（700, 28–32px）+ 摘要（muted, 2–3 行 `-webkit-line-clamp`）+ 元信息行（作者·日期·阅读时长·阅读量）+ 标签 chips。柔光 `--shadow-sm`，hover 抬升 `-2px` + 阴影加深。
2. **网格卡**（两列）：封面（16px 顶圆角）+ 胶囊标签 + 标题（600, 20px）+ 摘要（2 行）+ 元信息；hover 同抬升。
3. **紧凑列表（compact，归档用）**：无封面，行布局——左侧 mono 日期（muted）+ 标题（500）+ 右侧 meta；行间 `1px --border` 基线分隔；hover 标题转 `--accent`。
- 分页：胶囊数字按钮，current = 主色实底白字。

### 5.3 正文排版 Article Body
- 阅读栏 `--measure:720px` 居中（双栏时左栏）。
- h1（display 40/700），可含 1 个 `hl` 高亮词；下接元信息行（作者·日期·时长·阅读量，muted small）。
- 首段 `.lead`：19px，引导语。
- 正文 17/1.8，段距 1.2em。
- h2/h3 带锚点（hover 显 `#`）。
- 引用 `blockquote`：左侧 4px `--accent` 竖条 + `--surface-2` 底 + 适当内边距，不斜体。
- 行内 `code`：`--surface-2` 底 + `--radius-xs` + mono + `--accent` 字色；代码块：`--surface-2` 底 + `--radius` + 细描边 + 语言标签 + 横向滚动。
- 图片：`--radius` + 居中 + `max-width:100%` + 可选居中 muted 图注。
- 链接：`--accent` 字色，hover 下划线滑入。
- 表格：描边 + 表头 `--surface-2` + 斑马行。
- 可选：顶部阅读进度条（主色 2px）+ 右栏 sticky TOC（当前节 `--accent`）。

### 5.4 评论区 Comments
- 标题「评论」+ 计数（small）。
- 评论卡：圆头像（pastel 底或图，48px，--radius-pill）+ 昵称（600）+ 日期（muted small）+ 正文 + 操作（回复/赞）。底色 `--surface-2` 或描边；hover 微提亮。
- 嵌套回复：左缩进 + 左侧 2px `--accent` 竖条。
- 评论表单：textarea（`--radius` + 描边，focus → 2px `--accent` 环）+ 提交胶囊按钮（主色实底 + `--glow-accent`）。
- 状态：加载骨架 / 空态（人话文案）/ 失败重试，与全站一致。

### 5.5 页脚 Footer
- 多列：品牌块（logo + 标语，博客化改写如「记录，让思考更有温度」）+ 导航列（分类/关于/友链）+ 订阅块（email 输入 + 主色胶囊「订阅」）。
- 上方可选柔渐变 CTA 带（浅蓝→白）承接「订阅更新」。
- 顶部 `1px --border` + `--sp-8` 纵向留白；底部条：版权 + 主题切换 + 回顶。
- 社媒图标用内联 SVG（圆形 pastel 底 + `--muted` 图标），零图标库依赖。

### 5.6 通用元素
- **按钮三档**：主（accent 实底白字 + glow，hover 深一档 + 抬升）、次（accent-2 实底）、幽灵（描边 + ink 字，hover `--surface-2`）；全部 `--radius-pill`，`transition:160ms`。
- **胶囊标签**：`--radius-pill` + pastel 底 + 对应深一档字（如分类蓝、标签灰），无描边。
- **卡片**：`--surface` + `1px --border` + `--radius-lg` + `--shadow-sm`；hover（列表/头条）抬升 `-2px` + `--shadow`。
- **表单**：input/textarea `--radius` + 描边，focus → `--accent` 环（offset 2px）；label 500。

## 6. 交互与状态

- **动效预算（克制）**：胶囊下划线 150ms ease、卡片抬升 200ms `cubic-bezier(.2,.7,.2,1)` + 4px、颜色/淡入 160–200ms；**仅 3 类主形变**，不引入第四处。
- **hover**：导航下划线滑入、卡片轻抬、链接下划线、按钮深一档。
- **active/press**：按钮 `translateY(1px)`。
- **focus-visible**：2px `--accent` 环 + offset 2px（键盘可达性）。
- **主题切换**：颜色 200ms 过渡。
- **reduced-motion**：`@media (prefers-reduced-motion: reduce)` 关闭抬升/下划线位移，仅保留颜色。

---

## 7. 明暗与移动端

- **深色映射**见 §2.2；切换仅换 `:root[data-theme=dark]` 令牌，结构不变。
- **移动（<768）**：容器内边距 `--sp-4`；导航 → 抽屉；列表/双栏 → 单列（侧栏 TOC 下移或隐藏）；字阶下调（display 30 / h1 26 / 正文仍 17 但收紧行高至 1.75）；间距缩至 `--sp-6/--sp-7`；胶囊标签与按钮保持可用触控尺寸（≥40px 高）。
- **零横向滚动**为硬指标（已在 §4.4 容器约束 + 代码块横向滚动内部化保证）。

## 8. 与原站关键差异 & 落地提示

**与原站差异（博客化迁移落点）**
- 去掉四宫格 pastel 功能卡、密集仪表盘渐变 → 改为克制的标签/图标 pastel 点缀。
- 梯度过载收束为「品牌标 + 可选 hero 微渐变」两处。
- 阅读栏固定 720 + 稳定 17/1.8 + 描边无影 → 原站无长文场景，此为重点新增。
- 复用原站范式：胶囊标签→标题→描述 的栏目头、双胶囊导航按钮、柔光阴影、蓝绿双色、圆润尺度。

**落地提示（待确认）**
- 本规范与已落地的「登记簿 / The Numbered Register」方向**不一致**（配色由青绿 `#1B7174` 改为蓝 `#2563EB`+绿 `#10B981`，结构由「左缘登记轨编年流」改为「airy 卡片 + 柔光」）。
- 若采用本语言，落地路径：重写 `public/css/theme.css` 令牌层与组件（删登记轨/登记带，加柔光卡/胶囊/蓝绿双色），改写 `views/**/*.ejs`（导航双胶囊、列表 featured+grid+compact、正文栏、评论卡、页脚多列）。
- 建议先以本文件为契约出一份高保真呈现页（三页 × 明暗 × 桌面/移动）验收，再决定是否替换生产。
